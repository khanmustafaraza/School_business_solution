🚀 ERP SaaS VPS FULL MASTER GUIDE (HOSTINGER + NODE + BACKUP)

1. What is VPS?

A VPS is your own private Linux computer on the internet where you host your ERP SaaS backend, database, and APIs.

Flow: User → Domain → Nginx → Node.js → Database → Backup System

2. How to Buy Hostinger VPS

  1. Go to Hostinger VPS page
  2. Choose VPS plan (4GB RAM recommended)
  3. Select Ubuntu 22.04 OS
  4. Complete payment
  5. Wait for server activation
Always choose Ubuntu for Node.js SaaS hosting.

3. How to Login to VPS

Open terminal or PowerShell:

ssh root@YOUR_VPS_IP

Example:

ssh root@123.45.67.89

Enter password provided by Hostinger.

First login gives full server control (root access).

4. First Server Setup

sudo apt update && sudo apt upgrade -y

This updates server packages and security patches.

5. Install Node.js

curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v

Node.js runs your ERP backend APIs.

6. Install PM2 (Important)

npm install pm2 -g

Start backend:

pm2 start server.js --name ERP
pm2 save
pm2 startup
PM2 keeps server running even after reboot or crash.

7. Install Nginx

sudo apt install nginx -y

Nginx forwards domain traffic to Node.js backend.

Config:

server {
    listen 80;
    server_name yourdomain.com;

    location / {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }
}

8. Domain Setup (Hostinger DNS)

  1. Open Hostinger dashboard
  2. Go to Domain → DNS settings
  3. Add A record:
Type: A
Name: @
Value: YOUR_VPS_IP
This connects your domain to VPS server.

9. SSL (HTTPS Security)

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com

Enables secure HTTPS connection.

ERP without HTTPS is unsafe for financial data.

10. MongoDB Backup System (CORE PART)

Manual backup:

mongodump --out /var/backups/erp

Compress backup:

tar -czvf backup.tar.gz /var/backups/erp

11. Node.js Auto Backup Script

const { exec } = require("child_process");

const date = new Date().toISOString().split("T")[0];
const path = `/var/backups/erp/backup-${date}`;

exec(`mongodump --out ${path}`, (err) => {
    if (!err) {
        console.log("Backup created");

        exec(`tar -czf ${path}.tar.gz ${path}`);
    }
});
This script creates automatic daily backups.

12. Cron Job (Auto Run Backup)

crontab -e

Add:

0 2 * * * /usr/bin/node /var/www/erp/backup.js
Runs backup every day at 2 AM automatically.

14. Final SaaS Rules (VERY IMPORTANT)

  • Always use HTTPS
  • Always use PM2
  • Always take backups
  • Never expose database publicly
  • Always use companyId for isolation
  • Test restore backups regularly
If backup fails, your entire SaaS can collapse. Backup is more important than code.
